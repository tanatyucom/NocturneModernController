# Nocturne Modern Controller v3.0.0

## Highlights

- **Gameplay features are now separate mods.** Force Encounter, Quick Heal, Dash / Dash Keep, and Smart Auto Battle moved out of the Controller into four standalone mods. Each works on its own; with the Controller installed it joins the settings window and the key bindings.
- **The Controller is the controller core:** right-stick camera and PUZZLE turning, context-specific bindings, editing of the game's native key config (GAME Bindings), and the integrated settings window.
- **Editable native GAME Bindings:** 15 verified actions, 12 buttons, saved through the game's own key config and kept across restarts, with duplicate rejection and automatic rollback.
- **Selectable values in the MOD Features tab:** mods can offer choices besides on/off (Smart Auto Battle's mode and speed).
- **Smart Auto Battle: disabling it now fully disables it.**

## Modular gameplay features

| Mod | Version | Without Controller | With Controller (default, rebindable) |
|---|---|---|---|
| NocturneForceEncounter | 0.2.0 | X | X |
| NocturneQuickHeal | 0.1.0 | SELECT | RB |
| NocturneModernDash | 0.1.0 | Hold LT/RT, LT+RT for Keep, keyboard P | LT/RT, Keep LT+RT, keyboard P |
| NocturneSmartAutoBattle | 0.1.0 | The game's Auto button | The game's Auto button (no own binding); Enabled / Mode / Speed cards |

All four are optional. Install only the ones you want.

Smart Auto Battle: Normal Attack Only keeps the game's own Auto; Skill Priority picks commands and single targets. Speed x1.0 / x1.5 / x2.0 applies only while the game's Auto is on in battle. Disabled means no speed change, no command or target replacement, and no learning; the game's Auto runs unchanged. (In v2.x the built-in version kept replacing commands and learning even when disabled.)

## Upgrade from v2.0.3

Updating only the Controller removes Dash / Dash Keep, Quick Heal, Force Encounter, and Smart Auto Battle. Extract the matching mod ZIPs to keep them.

- On first run each mod takes its old values from `NocturneModernController.settings.json` (`ForceEncounterEnabled`, `QuickHealEnabled`, `DashEnabled`, `SmartAutoEnabled`, `AutoBattleMode`, `AutoBattleSpeed`); Smart Auto Battle also copies `NocturneModernController.smart-auto-knowledge.json`. The old values and files are left in place.
- Bindings you changed for Force Encounter, Quick Heal, Dash, and Dash Keep are used again (same action IDs).
- Smart Auto Battle's mode and speed moved from the removed Auto Battle tab to the MOD Features tab.
- If you remove a gameplay mod later, its bindings stay in `bindings.json` and are used again when you reinstall it. Nothing needs to be deleted.

## Installation

Extract each ZIP into the game folder (`smt3hd`). Every ZIP starts at `Mods/`. The Controller ZIP contains `Mods/NocturneModernController.dll` and the `Mods/NocturneModernController.Helper/` folder; each gameplay mod ZIP contains one `Mods/<Mod>.dll`. Settings files are created on first run.

## Compatibility

- **Do not combine the new gameplay mods with Controller v2.0.3 or earlier.** The old Controller contains the same features, so both would run (duplicate command selection and speed writes in Smart Auto Battle, for example). Use Controller 3.0.0 or later.
- Gameplay mods integrate with Controller 3.0.0 or later. Smart Auto Battle's Mode and Speed selectors need 3.0.0.
- The MOD Features integration still accepts mods built for earlier Controller versions.

## Verification

- All eight projects (Controller, Input Helper, Settings, tests, and the four gameplay mods) build with warnings as errors; the test suite passes.
- Two release builds from the same commit produced identical hashes for all five ZIPs.
- No gameplay mod DLL references the Controller assembly.
- In game, from the release packages:
  - Controller 3.0.0 with all four mods: every mod reports Controller integration; right stick, GAME Bindings (34/34 native slots read), Dash, Quick Heal, Force Encounter, and Smart Auto Battle (Skill Priority, x2.0, speed restored on victory) work; Harmony patches: Controller 4, Force Encounter 3, Quick Heal 1, Dash 3, Smart Auto Battle 9, no duplicates.
  - Upgrade from v2.0.3 data: with the mods' own settings removed, all four took their values from the old Controller settings and Smart Auto Battle copied the old knowledge; the results matched the previous files exactly, and the old saved bindings were used.
  - Controller 3.0.0 alone: only the Right Stick Camera card, no Auto Battle tab, no gameplay code running, the game's own Auto unchanged, Settings opens and closes normally.
  - Each gameplay mod on its own without the Controller (during development, with the same binaries).

## Known limitations

1. The new gameplay mods are not supported with Controller v2.0.3 or earlier (see Compatibility).
2. Smart Auto Battle's speed is verified to return to normal on victory and when Auto is turned off. Escape, game over, and returning to the title have not been exhaustively tested.
3. While the game window is inactive (alt-tab) during Smart Auto Battle at x1.5 / x2.0, how the game's time scale is handled is not fully understood. No effect on battle progress was observed.
4. Holding Select while the Settings window is open counts as a new long press, so Settings opens again right after you close it. This behavior is unchanged from earlier versions.
5. PUZZLE right-stick rotation is implemented but still needs final real-play verification. PlayStation, Switch, and generic SDL controllers have not been tested model by model.
6. Errors logged by other, unrelated mods are outside this project.
