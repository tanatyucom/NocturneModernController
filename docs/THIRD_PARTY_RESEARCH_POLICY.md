# Third-party research policy

## Prey Eyes 2 / SMT3HD Gameplay Hacks and Tweaks

Nocturne Modern Controller was informed by behavioral research of Prey Eyes 2
by sevrL_bats. The inspected 2026 distribution archive included MIT license
files, while other distribution pages have reportedly displayed different
reuse or modification terms.

License files found in a specific inspected source archive apply only to that
identified archive/version. They are not treated as overriding separate reuse,
redistribution, or modification notices shown on GameBanana, Nexus Mods, or any
other distribution page. When those statements differ or their scope is
unclear, this project does not copy code or assets from that source.

To avoid ambiguity, this project follows these rules:

- No Prey Eyes 2 source file is copied into or compiled by this project.
- No Prey Eyes 2 binary, image, icon, or other asset is redistributed.
- No GameBanana or Nexus permission statement is inferred from an MIT file
  found in a different archive, and the reverse is also true.
- Implementations are written independently against SMT3 HD game behavior and
  game API observations.
- Names of game methods, runtime observations, data formats, and general design
  ideas may be used as research facts.
- If third-party code or assets are intentionally incorporated in the future,
  their exact origin, version, license text, and required attribution must be
  reviewed and recorded before inclusion.

Research copies are kept only in the local, Git-ignored
`.tmp_gameplay_hacks_reference/` directory.
